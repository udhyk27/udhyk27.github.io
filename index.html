블록체인 서버 이상 감지 및 Discord 알림 구축

blog
BesuBashnode_exporter
상황
Hyperledger Besu 기반 프라이빗 블록체인을 VM에서 운영 중 프로세스 종료, RPC 멈춤, VM 다운이 발생했고 직접 접속하기 전엔 상태를 알 수 없었습니다.
원인
VM 내부에서 자기 자신을 감시하면 VM이 죽을 때 모니터링도 함께 멈춥니다. 또한 VirtualBox NAT 주소 변환으로 방화벽 화이트리스트가 어긋났고, Rocky Linux의 SELinux 라벨 문제로 node_exporter 실행이 실패했습니다.
해결
감시를 별도 VM으로 분리해 ping, RPC, Peer 수, 블록 생성, 디스크를 점검하고 상태가 바뀔 때만 Discord 알림을 보내도록 구성했습니다. tcpdump로 실제 출발지 IP를 확인해 방화벽을 수정하고 restorecon으로 SELinux 라벨을 복구해, 약 1분 내 장애 감지를 달성했습니다.

GitHub Push → Notion 자동 동기화 구축

blog
GitHub ActionsNode.jsNotion API
상황
GitHub에서 Markdown으로 문서를 관리했지만 원본만으로는 가독성이 떨어져, push 시 Notion 페이지가 자동 생성·갱신되도록 동기화 구조를 만들었습니다.
원인
Actions가 만든 commit이 다시 워크플로를 트리거해 무한 실행됐습니다. frontmatter의 notion_page_id가 저장되지 않아 수정할 때마다 새 페이지가 생겼고, Notion API에는 본문 일괄 교체 엔드포인트가 없어 블록을 직접 갱신해야 했습니다.
해결
commit 메시지에 [skip ci]를 붙여 루프를 막고, Actions가 page_id를 commit back하도록 구성했습니다. git diff status(A, M, D, R)로 생성·수정·삭제·이동을 분기해 push 후 약 30초~1분 내 Notion에 반영되도록 했습니다.
